Raspberry Pi Controller Schematic

The detailed view of the controller block on the water-system schematic: a Raspberry Pi Zero 2 W reads soil, weather and tank sensors, then opens the zone valves (and the pump, when one is fitted) on a schedule it adapts to weather and season. Low-cost, low-power, and fully offline once configured.

Controller block diagram

How it decides when to water

  1. Season sets the baseline (DS3231 clock). The real-time clock keeps the date without any network, so the Pi runs a different base schedule for the dry season (frequent short runs) than for the monsoon months (mostly off).
  2. Weather can veto a run (rain + soil-moisture sensors). A scheduled run is skipped when it is actively raining or the soil probes already read wet, so the system never wastes tank water on a wet field.
  3. Heat can add a run (DHT22). On unusually hot, dry-air days the controller adds a short extra pulse to the driest zone.
  4. The tank guards the pump (level sensor). The pump contactor only engages when the buffer tank needs refilling and the source has water, so the pump can never run dry.
  5. One zone at a time. The relay opens a single zone valve per run, matching the zoning logic in the pressure planner, so a small source can still feed the whole farm.

Everything runs locally on the Pi; no internet is required in the field. The run log doubles as pilot-study data: every watering, skip and tank refill is time-stamped for Muravah's dataset.

Bill of materials: Pi Zero 2 W (US$15 list), MCP3008, DHT22, DS3231, capacitive soil probes, rain sensor, float switch, 4-channel relay, 12 V solenoid valves, buck converter, enclosure. Budgeted at ~₱8,000 per farm in the pilot ledger. Pairs with the water-system schematic, where this whole page is the single amber controller block.
