Bicol cacao field tools

Cacao Bicol Field Tools

Field tools built from interviews with cacao farmers and processors in Bicol, Philippines. Water pressure — not water scarcity — came up as the concrete, solvable engineering problem, so these tools focus there.

Calculator

Drip Pressure Planner

Turns a farm's size and water source into tree count, flow demand, required pressure, irrigation zones, and buffer tank size.

 Diagram

Drip System Schematic

A P&ID-style diagram of the same drip system, toggling between a gravity-fed source and a source below the field.

 Editor

Schematic Editor

Drag nodes, wire new connections, and add components to either diagram — the system schematic or the planner's mini diagram.
